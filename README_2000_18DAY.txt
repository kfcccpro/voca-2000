■ r3 변경 사항

 [학습 흐름]
  1. 당일 오답은 실제 정답을 붉은색으로 3초 표시한 뒤 자동으로 다음 문제로 이동합니다.
     별도의 인지 단계는 없습니다.
  2. 오답은 D+1 → D+3 → D+6 → 안정화(STABLE) 단계로 예약 복습됩니다.
     D+3 이후 재오답은 집중 케어(FOCUS) 상태로 이관됩니다.
  3. 예약 복습에서 다시 틀렸을 때만 한글 뜻 인지 화면이 실행됩니다.
     영단어를 고정하고 한글 뜻을 글자별로 표시하며, 진행 막대 없이 4초 후 NEXT가 활성화됩니다.
  4. DAY 본 시험은 설정된 문제 수와 관계없이 해당 DAY 전체 단어를 출제합니다.
     문제 수 설정은 자유 연습과 오답 재시험에만 적용됩니다.

 [채점 정확도]
  5. 주관식 채점을 강화했습니다. 뜻 문자열의 짧은 조각만 입력해도 100점 처리되던 문제를
     차단했습니다. (예: influence 의 뜻에 "사람"만 입력 → 이전 100점, 현재 오답 25%)
     정당한 어간 답안은 그대로 인정합니다. (공급 / 발전 / 수평 / 평평 / 봉사 / 총계 등)
  6. 뜻 표기 "발달[발전]하다" 의 확장 규칙 오류를 바로잡았습니다.
     이전에는 "발달발전하다" 로 잘못 확장되었습니다. 대괄호가 바로 앞 어절을 대체하도록
     수정했습니다. "영향을 미치는 것[사람]" → "영향을 미치는 것" / "영향을 미치는 사람"
  7. 한→영 주관식에서 뜻이 같은 동의어를 함께 정답 처리합니다.
     예) "놀라게 하다" → amaze / astonish / astound 모두 정답 (16쌍 33단어)
  8. 4지선다에서 정답과 글자가 완전히 같은 보기가 오답으로 출제되던 문제를 없앴습니다.
     보기 생성 시 표시 텍스트 중복을 제거하고 판정도 텍스트 기준을 함께 봅니다.
